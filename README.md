# Mother's Day 🌸

A beautiful website dedicated to celebrating mothers around the world, created with pure HTML, CSS, and JavaScript.

## 🌟 Features

- Beautiful and responsive design
- Interactive elements to celebrate mothers
- Smooth animations and transitions
- Mobile-friendly layout
- Pure HTML/CSS/JS implementation - no frameworks needed!

## 🚀 Getting Started

This is a static website that can be run directly in any modern web browser.

1. Clone or download this repository
2. Open `index.html` in your web browser
3. That's it! No installation or setup required

OR

You can access this website here: https://mother-s-day-seven.vercel.app/


## 💻 Tech Stack

- HTML5 - Structure
- CSS3 - Styling and animations
- JavaScript - Interactivity
